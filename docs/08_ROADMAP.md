# 08. Roadmap — план по шагам

Правило: одна задача = одна сессия Claude Code = один коммит.
После каждой задачи — отметить `[x]` в этом файле.
«Готово, когда» — критерий, который проверяет ЧЕЛОВЕК своими руками.
Обясняй что и как работает после каэдого шага максимально понятно.

## Фаза 6. Офлайн-режим и синхронизация
Данные и расчёты переезжают на телефон, сервер становится хранилищем копии (`02_ARCHITECTURE.md`).
Порядок важен: старые эндпоинты сервера удаляются только в конце (6.13), чтобы приложение
работало после каждого шага.
- [x] 6.0 Документы: офлайн, синхронизация, гостевой режим, пароль в профиле, расчёты на телефоне
- **Backend**
- [x] 6.1 Поля синхронизации: `version` из `sync_version_seq`, `deleted_at`, частичный UNIQUE листов,
  `users.name_version`; миграция; id записей может прийти от клиента
- [x] 6.2 `POST /sync`: приём изменений, `rejected`, курсор, мягкое удаление, выдача изменений
  - Готово, когда: в Swagger `/sync` с `cursor: null` и новым авто → авто вернулось с курсором;
    повторный `/sync` с этим курсором → пустые списки; тесты (успех, 401, чужой id, нет родителя,
    `SHEET_EXISTS`, удаление, частичное отклонение) зелёные
- [x] 6.3 `PUT /me/password` + `has_password` в `/me` и ответах входа
  - Готово, когда: задал пароль через Swagger → `/auth/login` с ним пускает без SMS
- **Android**

## Фаза 9. Новый внешний вид (дизайн из Google Stitch)
Правила фазы:
- Меняется **только внешний вид**: цвета, шрифты, отступы, формы карточек и кнопок, иконки.
  Логика, формулы, поля, навигация и смысл текстов остаются как в `07_UI_SCREENS.md`.
- Если в дизайне появилось то, чего нет в `07_UI_SCREENS.md` (новая кнопка, график, поле), Claude
  сначала предлагает правку документа и ждёт подтверждения. Если чего-то нет в дизайне, а в
  контракте есть, — оставляем, оформляем в общем стиле.
- Остаёмся на Material 3 (Compose): дизайн из Stitch переносится в тему и компоненты, HTML из Stitch
  в приложение не встраивается, он нужен только как образец (точные цвета, размеры, шрифты).
- Светлая и тёмная тема обязательны. Тексты — по-русски, как в приложении сейчас.
