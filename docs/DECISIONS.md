# Журнал решений (ADR-lite)

Записывать сюда каждое заметное решение: что выбрали, почему, какие были альтернативы.
Новые записи — сверху. Формат: дата · решение · причина.

- 2026-10 · Выдача JWT (access + запись refresh в `refresh_tokens`) сделана в задаче 2.2, а не 2.3 · по контракту verify-code сразу возвращает токены; в 2.3 остаются проверка токенов, refresh, logout, `/me`
- 2026-10 · Отключённый пользователь (`is_active=false`) на request-code получает 403 `PHONE_NOT_ALLOWED` · контракт не меняется, SMS не тратится
- 2026-10 · Лимит запросов кода по IP — счётчик в памяти процесса (`SlidingWindowLimiter`), время — зависимость `get_now` · как в 05_AUTH_SMS для MVP; часы подменяются в тестах

- 2026-10 · Запасной вход по паролю (`POST /auth/login`), логин = номер телефона, пароль выдаёт человек командой `python -m app.cli set-password`; пользователь пароль не меняет; тестового аккаунта для пароля нет · если SMS не пришла, задать пароль через приложение невозможно; отдельный логин не нужен — телефон уже уникален. Альтернативы: отдельное поле login, смена пароля в профиле — отклонены для MVP
- 2026-10 · Хэш паролей — `hashlib.scrypt` (stdlib), блокировка 15 мин после 5 ошибок · без новой зависимости (bcrypt/argon2 не нужны для десятков пользователей), защита от подбора

- 2026-10 · Enum-поля в БД — varchar + CHECK (`native_enum=False`), не PostgreSQL ENUM · совпадает с 03_DATA_MODEL (varchar), новое значение добавляется без ALTER TYPE
- 2026-10 · UUID первичных ключей генерирует Python (uuid4), не БД · id известен до INSERT; единые имена ограничений (naming convention) для стабильных миграций
- 2026-10 · uvicorn как ASGI-сервер, база `fuel_test` создаётся init-скриптом PostgreSQL · стандартный сервер для FastAPI; тестовая БД в том же контейнере, как требует 09_TESTING.md
- 2026-10 · Монорепо (backend + android в одном репозитории) · проще новичку, Claude видит контракт и обе стороны сразу
- 2026-10 · Backend на Python/FastAPI · простой синтаксис, автодокументация Swagger, удобно тестировать
- 2026-10 · Расчёты ЛУТ только на backend · одна точка истины, Android не дублирует формулы
- 2026-10 · Дробные числа в API — строки · исключить ошибки float в литрах и деньгах
- 2026-10 · SMSGate в режиме Cloud на старте · домашний телефон за NAT, не нужен проброс портов
- 2026-10 · Норма расхода копируется в ЛУТ при создании · смена нормы не меняет прошлые месяцы
- 2026-10 · MVP без офлайна · сократить сложность; добавить Room позже при необходимости
- 2026-10 · Ошибки валидации — 400 `VALIDATION_ERROR` (не 422 FastAPI); неизвестный URL/метод — 404 `NOT_FOUND`; сбой — 500 `INTERNAL_ERROR` · 422 зарезервирован под `BUSINESS_RULE`, клиенту достаточно одного кода «не найдено»
