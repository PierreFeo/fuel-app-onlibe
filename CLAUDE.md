# CLAUDE.md — Fuel Tracker (учёт топлива личных автомобилей)

Этот файл Claude Code читает автоматически в начале каждой сессии.
Здесь — главные правила проекта. Подробности — в папке `docs/`.

## Что это за проект
Мобильное приложение (Android) для учёта топлива личных автомобилей сотрудников организации.
Пользователь добавляет свои автомобили, выбирает один и ведёт по нему ЛУТ — листы учёта топлива
(одна карточка = один месяц): пробег на начало/конец месяца, заправки, остаток в баке, пробег за
месяц и расход. **Приложение работает без интернета**: данные и расчёты — на телефоне (Room).
Вход (код из SMS или пароль) нужен только для синхронизации с сервером по кнопке; без входа —
гостевой режим, данные только на телефоне.

## Главные правила работы
1. **Документы в `docs/` — контракт.** Код должен им соответствовать. Если задача требует
   отступить от контракта — СНАЧАЛА предложи правку документа и дождись подтверждения,
   потом меняй код. Никогда не меняй API молча.
2. **Один шаг за раз.** Работай по `docs/08_ROADMAP.md`. Не делай задачи из следующих фаз,
   если об этом не попросили.
3. **Сначала план, потом код.** Для любой задачи больше одного файла — сначала короткий план
   (какие файлы создашь/изменишь и зачем), затем реализация.
4. **Тесты обязательны** для бизнес-логики (расчёты ЛУТ), авторизации и каждого эндпоинта API.
   Задача считается выполненной, только когда тесты проходят.
5. **Пользователь — новичок.** В конце каждой задачи кратко объясняй простыми словами:
   что сделано, как это проверить руками (конкретные команды/клики), что дальше.
6. **Секреты не коммитим.** Пароли, токены, ключи — только в `.env` (он в `.gitignore`).
   В репозитории — только `.env.example` с фиктивными значениями.
7. **Не добавляй библиотеки без причины.** Новая зависимость — объясни зачем, запиши в `DECISIONS.md`.
8. **Язык:** код, имена переменных, таблиц, эндпоинтов — на английском.
   Тексты интерфейса, комментарии к сложным местам, объяснения пользователю — на русском.
9. **Деньги и литры — не float.** На backend — `Decimal`, на Android — `BigDecimal` или строки
   из API. Пробег — целые километры.
10. **Расчёты и бизнес-проверки делает Android** (`domain/calc/`, см. `06_BUSINESS_RULES.md`).
    Сервер только хранит данные и отдаёт их при синхронизации — формул на сервере нет.

## Глоссарий
| Термин | Значение | В коде |
|---|---|---|
| ЛУТ | Лист учёта топлива за один месяц по одному авто | `FuelSheet`, таблица `fuel_sheets` |
| Заправка | Одна покупка топлива | `Refueling`, таблица `refuelings` |
| Одометр | Показание пробега на приборной панели, км | `odometer_*_km` |
| Норма расхода | Литров на 100 км, у авто летняя и зимняя; в ЛУТ — копия для его сезона | `norm_l_per_100km`, `norm_winter_l_per_100km` |
| Сезон | Лето ☀️ / зима ❄️ у ЛУТ, выбирает норму | `season`: `SUMMER` / `WINTER` |
| Остаток | Топливо в баке, литры | `fuel_*_l` |
| OTP | Одноразовый код из SMS | `otp_codes` |
| Синхронизация | Отправка изменений с телефона и получение изменений с сервера по кнопке | `POST /sync`, `SyncRepository` |
| Гость | Режим без входа: данные только на телефоне | `AppMode.GUEST` |

## Команды (подробнее — в CLAUDE.md подпапок)
- Backend: `cd backend && docker compose up -d` · тесты: `docker compose exec api pytest`
- Android: собирать и запускать из Android Studio; тесты: `cd android && ./gradlew test`
