Как установить

  1. Нажмите «Скачать для Android» и откройте файл fuel-tracker.apk.
  2. Если телефон спросит — разрешите установку из этого источника, вернитесь назад и нажмите «Установить».
  3. Если Play Защита предупредит о неизвестном приложении — «Подробнее» → «Всё равно установить».
  4. Откройте «Учёт топлива», введите номер телефона и код входа. При первом входе задайте пароль — дальше входите по нему.

Обновление — по этой же ссылке, удалять старую версию не нужно. Данные сохранятся.
