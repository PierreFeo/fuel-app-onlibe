⛽ Учёт топлива

Листы учёта топлива личных автомобилей. Работает без интернета.

Скачать для Android
  1. Откройте скачанный файл fuel-tracker.apk.
  2. Если телефон спросит — разрешите установку из этого источника, вернитесь назад и нажмите «Установить».
  3. Если Play Защита предупредит о неизвестном приложении — «Подробнее» → «Всё равно установить».
  4. Откройте «Учёт топлива» и войдите по номеру телефона и коду из SMS.
Обновление — так же по этой ссылке, удалять старую версию не нужно.
